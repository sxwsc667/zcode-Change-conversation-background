# 接手与测试报告

日期：2026年10月8日。

## 完成内容

1. 继续完成原项目未收尾的通用版，而不是重做背景设计。
2. 统一制作、安装、换图、恢复入口，增加共享安全检查和版本限制。
3. 修复恢复工具可能覆盖升级后的程序、恢复失败不完整回退的问题。
4. 增加当前包登记和排他操作锁；缺少记录、恢复点损坏、当前包不匹配均拒绝继续。
5. 制作期间检测源包变化；失败清理本次未完成输出，已有成果不覆盖。
6. 保留本机兼容入口：首次使用只登记已核验的现有背景与原始备份，再调用新工具。
7. 更新中文说明、补齐自动化测试，分离本机包和可分享包。

## 包内核验

原版包含27068个文件，生成补丁包含27069个文件。生成补丁只更新界面入口并新增一张壁纸，其余原始包内内容保留；27057个含完整性记录的包内文件通过核验。

12个外置运行组件的原版索引和外置标记由新制作工具原样保留，工具不修改磁盘上的这些组件。完整流程测试主要针对程序资源包，不代表重新运行验证了全部外置组件功能。

新增样式对应的界面入口与目前已安装背景的界面入口逐字节一致。预览素材仍使用之前的实际测试截图，本轮未重新启动正式应用做视觉验收。

另一个接手发现：旧方法重新打包后的12项外置组件索引，和原始备份中的索引有差异；旧包内的其他普通文件除界面入口外没有变化。本轮没有据此修改外置组件，也不把旧说明中的“所有元数据一致”当作新结论。新工具直接保留原版索引，避免沿用这种重新打包差异。

- 未进行断电、操作系统崩溃或磁盘硬件故障测试；改名替换不是断电级事务。
- 本轮没有重新启动正式软件、没有改登录凭据、没有迁移聊天记录。
- 本机版首次实际使用时会创建新的安装记录和恢复点；本轮只在副本上验证了该过程。
