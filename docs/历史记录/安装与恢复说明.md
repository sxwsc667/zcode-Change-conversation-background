## 自己更换壁纸

第一次使用前，需要先安装背景补丁。

1. 从电脑右下角托盘彻底退出智码。
2. 双击“更换壁纸.cmd”（更换壁纸命令工具）。
3. 在弹出的窗口中选择新图片。
4. 等待出现“壁纸更换成功”，重新打开智码。

此工具只替换程序包中的壁纸，保留原来的遮罩、侧边栏和输入框样式。
图片会自动转换为适合使用的格式；取消选择不会改变当前程序。
每次更换前都会保留旧程序包，并检查其余文件内容没有变化。
已使用桌面的原始角色图片在测试安装中验证过，新图片可以从程序包正常读取和解码。

注意：桌面的“对话背景.jpg”（对话背景图片）只是导出的素材副本，修改它不会自动影响程序。
应使用“更换壁纸”工具选择你要使用的图片。

更换壁纸后不要重复运行初次安装工具；要换回默认界面，请使用恢复默认背景工具。
